# Local PDF Extraction

Use this repository only for local PDF extraction. Read `pdf-extractor-local/SKILL.md`, run `bash install.sh` once on a supported computer, then use `pdf-extractor-local/scripts/extract_pdf.py`.

Never replace the bundled runtime, OCR models, PDF renderer, or Tesseract binary with a system-installed version. Do not upload PDF contents to cloud OCR or a generative AI service. Return the output paths and report `open_issues` from the script's JSON output.
